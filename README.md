# Street View Photographer 📸

**Street View Photographer** is a Chrome extension designed for photographers, directors, and location scouts. It overlays a professional "Director's Viewfinder" on Google Street View, simulating real lens focal lengths, aspect ratios, and sensor sizes to help you frame your shots virtually.

## ✨ Features

* **Precise Focal Length Simulation**: Supports 12mm to 200mm, with quick toggles for common primes (24mm, 35mm, 50mm, 85mm).
* **Cinematic Aspect Ratios**:
    * **Cinema**: 16:9 (HD), 2.39:1 (Anamorphic)
    * **Photo**: 3:2 (Full Frame), 4:3 (TV)
    * **Social**: 4:5 (Portrait), 9:16 (Stories), 1:1 (Square)
* **Sensor Size Customization**: Full Frame (36mm), APS-C, Micro 4/3, etc.
* **Composition Aids**: Rule of Thirds grid and Vignette mode.
* **FOV Locking Algorithm**: Automatically detects the Street View Map's FOV to ensure the frame matches the real-world lens perspective.

## 🚀 Installation

### Option 1: Chrome Web Store
[Download from Chrome Web Store](https://chromewebstore.google.com/detail/gnibpelabnppajmbbpiakgnphmlkhcjj?utm_source=item-share-cb)

### Option 2: Manual Installation (Developer Mode)
1. Clone or download this repository.
2. Open Chrome and go to `chrome://extensions/`.
3. Enable **Developer mode** in the top right.
4. Click **Load unpacked** and select this project folder.

## 🎮 Usage

1. Go to [Google Maps](https://www.google.com/maps) and enter Street View mode.
2. Click the **Camera Icon** button at the bottom right to open the settings panel.
3. **Show Frame**: Toggle the viewfinder on/off.
4. **Focal Length**: Use the slider or input box to adjust the lens.
5. **Aspect Ratio**: Select your desired framing ratio.

# 📸 Street View Photographer (中文介紹)

**Street View Photographer** 是一個 Chrome 瀏覽器擴充功能，專為攝影師、導演與勘景人員設計。它能在 Google Street View (街景服務) 上疊加專業的「導演觀景窗」，模擬真實鏡頭的焦距、視角與構圖，讓你在虛擬勘景時也能精準掌握畫面。

## ✨ 主要功能

* **精準焦段模擬**：支援 12mm 到 200mm 的焦距模擬，並提供常用定焦鏡 (24mm, 35mm, 50mm, 85mm) 快速切換。
* **多種長寬比 (Aspect Ratios)**：
    * **電影類**：16:9 (HD), 2.39:1 (Anamorphic)
    * **攝影類**：3:2 (Full Frame), 4:3 (TV)
    * **社群類**：4:5 (Portrait), 9:16 (Stories), 1:1 (Square)
* **感光元件尺寸設定**：支援 Full Frame (36mm), APS-C, Micro 4/3 等不同片幅換算。
* **輔助構圖**：內建九宮格 (Rule of Thirds) 輔助線與暗角模式 (Vignette)。
* **高度鎖定演算法**：自動偵測街景地圖的 FOV (視野)，確保模擬框線與真實鏡頭視角一致。

## 🚀 安裝方式

### 方法一：從 Chrome 線上應用程式商店安裝
[點擊前往 Chrome Web Store](https://chromewebstore.google.com/detail/gnibpelabnppajmbbpiakgnphmlkhcjj?utm_source=item-share-cb)

### 方法二：開發者模式安裝 (手動安裝)
1. 下載此儲存庫 (Clone or Download ZIP)。
2. 開啟 Chrome 瀏覽器，進入 `chrome://extensions/`。
3. 開啟右上角的 **「開發人員模式」 (Developer mode)**。
4. 點擊左上角的 **「載入未封裝項目」 (Load unpacked)**。
5. 選擇本專案的資料夾即可。

## 🎮 使用說明

1. 前往 [Google Maps](https://www.google.com/maps) 並進入任一街景模式。
2. 點擊畫面右下角的 **圓形相機圖示** 開啟設定面板。
3. **Show Frame**：開啟/關閉觀景窗。
4. **Focal Length**：使用滑桿或輸入數值調整焦距。
5. **Aspect Ratio**：選擇你想要模擬的畫面比例。
